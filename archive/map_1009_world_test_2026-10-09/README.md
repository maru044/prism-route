# model_1009 临时大世界测试归档

归档日期：2026-10-09。用户要求将临时验证场景移出当前工作内容。

本目录以 `.gdignore` 排除 Godot 资源扫描和导入。内容按原项目目录结构保留，是历史快照，不是可以在当前路径直接运行的独立工程。

## 内容

- `scenes/`：1009 驾驶与地形对照场景。
- `scripts/`：专用场景逻辑和 11 m × 3 m 房车测试控制器。
- `assets/world/map_1009_test/`：原始平滑版、Blender 起伏版、占位地形材质、构建元数据及导入配置。
- `tools/`：历史生成、驾驶验证和截图合成工具。
- `screenshots/`：两版地形对比、驾驶和轮胎接地截图。
- [完整测试记录](docs/MAP_1009_DRIVE_RELIEF_TEST.md)：归档前的说明与实验结论。
- `evidence/verification.json`：归档前已完成的物理验证结果，不是本轮重新测试的数据。
- `manifest.json`：23 个迁移文件的原路径、长度和 SHA-256；迁移后逐个校验相同。

## 保留的设计结论

后续道路至少 20 m 宽，房车计划只在道路上行驶。实验噪声起伏暂不采用，微地形由用户在 Rhino 中手工塑形；噪声可用于部分纹理细节。

当前道路方案仍见 [道路实施计划](../../docs/ROAD_IMPLEMENTATION_PLAN.md)。
