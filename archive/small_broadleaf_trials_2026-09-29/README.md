# 小阔叶树实验归档（2026-09-29）

此目录保存已暂停使用的 v3、v4 小阔叶树尝试，供以后比较或重做。当前游戏和植被测试场景恢复使用稳定版 `tree_small_broad_canopy.glb`；实机小树的 LOD1、LOD2 也保持其原有资产。

- `models/`：实验 GLB 及 Godot 导入配置、导出贴图。
- `source/`：对应 Blender 源文件。
- `textures/`：实验叶簇贴图。
- `tools/`：贴图生成脚本及实验版植被生成器快照。
- `runtime_snapshots/`：实验期间的场景脚本与测试场景配置快照，仅作参考。
- `screenshots/`：当时的视觉对比图，包括覆盖过实机基准图的 v4 场地截图。

这些文件不参与当前运行。重新启用前须先在独立测试场景比较树冠形状、受光、实例密度和 LOD 衔接。
