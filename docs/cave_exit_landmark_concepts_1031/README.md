# 初始洞穴出口 · 下一处建筑构图

使用内置 image_gen 生成，提示词完整保存在 `prompts.json`。两图均以同一张实机截图为编辑参考，仅作艺术构图方案，没有修改 Rhino 或游戏。

位置建议：画面左侧约三分之一的对岸上层台地后缘，靠近既有桥面后方，避开中间水面圆岛。与右侧高桥塔构成左低右高的轮廓；具体台地坐标需要在选择方案后测量落位。

- `A_ribbon_pavilion_24m.png`：折带展馆，概念高约 24 米，横向舒展，宽约 55 米，作为安静的次级地标。
- `B_archive_landmark_36m.png`：档案／观察站，概念高约 36 米，较紧凑的竖向体量，宽约 32 米，暗色内腔及断开的楼层正对出洞视线，更容易成为明确探索目标。
- `original_view.png`：用户提供的实机原图。

推荐 B 的紧凑体量与开洞立面。高度先以台地面以上约 30–36 米作为体量预算；右侧桥塔继续保持最高点。A 适合偏重自然与横向连续景观的版本。

所有尺寸均为新建筑的概念预算，不是从截图获得的实测数据。生成图中的透视、细部与遮挡不作为精确尺寸依据，建模前需回到实际地图检查高度、桥缆遮挡及台地余量。
