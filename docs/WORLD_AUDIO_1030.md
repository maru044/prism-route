# 大世界首轮音效 · 2026-10-30

直接运行 F5 正式入口 `scenes/map_1021.tscn`，自动启用。

## 试听方式

- 左上角「声音 · 音量设置」：总音量、环境声、动作声，以及声音总开关。当前滑块在本次运行内有效；重启采用 `assets/audio/world_1030/settings.json` 默认值。
- 出生点「南侧亲水平台」附近听水岸声；接近海岸更响，远离或登高后降低。内湾岸边采用较弱浪声。
- 风力自动在微风 / 大风间变化，界面不显示风力调试按钮。树林附近的树叶声随真实风力平滑增强；空旷处不会到处响树叶声。
- 海岸偶尔播放海鸟；树林偶尔播放普通鸟叫。间隔、方位与少量音高变化，强风时普通鸟叫减少。洞顶遮挡会压低环境声并阻止近处鸟叫；水下压低声量并低通。
- 现有水面菜单的涉水检查点可检查脚步：复用原有浅水落脚 / 落地涟漪事件，六种短音效交替。停步、干地、驾驶或自由镜头不触发角色涉水声。
- C 切换房车，第一次起步播放启动声。同一次驾驶内停车再走不重播；切回人物再进入驾驶后重新启动。没有持续发动机循环。
- 自由镜头环境声跟随镜头位置，正常模式听音位置跟随角色 / 车辆；水面反射相机不参与听音定位。H 隐藏界面不静音。

## 实现与调节

`scripts/audio/world_audio_1030.gd` 负责位置、状态、音量总线与短音效；`ambient_bed.gd` 用双播放器做 1.5 秒等功率交叠循环。实际水面网格提取 2,818 段边界；树位置建立 2,905 个空间格，区域采样每秒四次，音量逐帧渐变。屋顶采用五条上向物理射线。没有改动角色碰撞、地形、树布局或草地烘焙。

资源位于 `assets/audio/world_1030/`，15 段音频合计约 5.39 MiB。默认响度与空间半径集中在 `settings.json`，可继续按试听调整。三条专用总线为 PR_World、PR_Ambience、PR_Actions；总线上有限幅，环境总线支持水下低通。

`tools/prepare_world_audio_1030.py` 从试听素材裁剪、归一化与转码，源文件保持不变。大风使用修复过响度和 ReplayGain 的 v3 试听版。海浪 / 风声为 Ogg，短音效为单声道 WAV。`manifest.json` 记录来源、作者、许可、源文件与派生文件哈希、剪辑位置及处理方法；`CREDITS.txt` 随游戏打包。四项 Freesound 素材目前使用公开 HQ 压缩试听文件，另外两项来自 OpenGameArt 原始 WAV，均保留明确记录。
