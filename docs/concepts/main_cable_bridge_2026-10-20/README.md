## 场地依据

读取 map_current.3dm 的主桥中线 5bd0e22f-8527-419b-be32-8db5b1c3232d，长约 988.695 m，Z=60 m。四处占位岛与路线的平面重合范围约为里程 40–133 / 449–560 / 606–767 / 818–920 m；第三岛现有占位顶面 Z=40 m，其余为 60 m。这些范围是用于设计定位的离散抽样，不是工程分跨长度。

参考：[Santiago Calatrava 的 Jerusalem Bridge of Strings 项目资料](https://calatrava.com/projects/bridge-of-strings-light-rail-train-jerusalem.html)。借鉴其倾斜塔及空间扇形斜拉索，岛体采用流动、连续的曲面建筑构思。

## A：弦帆列岛

[A_string_sail_islands.png](A_string_sail_islands.png)。三座高低错落的细长斜塔，由流线锚台和廊厅中延伸出来。四岛形成不同的锚固、上桥及临水空间，第三个较低的岛以抬高的支承臂托住路面。重点是细塔、空间索面和坡道之间的连续方向感。

## B：潮汐门庭

[B_tidal_gates_concept.png](B_tidal_gates_concept.png)。两座倾斜环形塔，下部与岛体两翼连续，四岛围合出水庭、临水廊厅和缓坡屋面。以大尺度空洞和厚实、可进入的建筑体量形成与 A 显著不同的轮廓。

**B 的场地偏差：图像生成器省略了原本位于主桥后方的中央 C 形大平台。两次局部修正均因网络请求失败而未得到结果，当前保留的 B 只用于比较主桥、桥塔与四个小岛的造型，不能作为删除中央平台或调整总平面的依据。** A 对该既有平台的保留更接近场地。两图在背景道路、旧化、植物与局部结构细节上均存在生成式艺术化处理，后续精确建模仍须依据原模型。
