## 实体与开敞分布

西侧主台、东侧主台、中央连接体和湾缘低台，均从原顶面构建到底部基准 -2 米的闭合实体。两端落地段保留实心，没有建立重复支柱或连续镂空立面。

开口集中在两类位置：

1. 两条中层道路的穿越通道：按实际三维道路曲线预留拱形净空。
2. 东侧一段局部开敞廊：在原弧线参数归一化范围约 0.747–0.803 内退让实体底层，使用一个连续双支脚 SubD。邻接段及湾缘低台仍为实体，因此该处是局部支撑空间，不是将全部底层贯通挖空。

按各基准实体体积累计，扣除局部开敞区、道路通道及 T1 出口延伸后，保留约 **91.47%** 的实体体积。这个数值是逐体块体积之和的保留比例，未对体块重叠做全局布尔合并；不能当作严格的区域实体率或地面覆盖率。

## 原轮廓与连续支脚如何衔接

实体的上表面直接复制 v02 的实际修剪顶面，侧边和底部另行封闭。种植顶面也从 v02 保留。道路通道需要局部切除的区域除外，未用新样段替换整圈顶面。

局部 SubD 沿用 v03 的共享拓扑方法，重新采样东侧原顶面来确定位置、坡度和标高，同时调整腹部厚度。它与原顶面的覆盖体搭接，与两侧实体段保留接合余量；不是直接把独立样段放进场景。支脚、肩部和拱腹本身仍属于一个闭合 SubD。

原顶面覆盖体用于维持局部开敞区的原冠部轮廓。覆盖体、SubD 与邻接实体段目前是独立闭合对象，通过搭接组成设计草稿，尚未完成全部接缝的连续性修整或全域布尔合并。

## 验证与修正

本轮结构包括 5 个闭合实体段、1 个局部顶面覆盖体和1 个闭合 SubD；另有6 个开放种植曲面。相关原始模型几何 CRC 保持不变。

初次抽样发现 T1 实际路面的终端边缘超出旧净空体封口，剩余实体导致约 0.40 米的局部上方净空。已用顺道路切向的拱形出口延伸处理，向终点外延长45 米、宽34 米。检查了对应种植面的裁切需求，没有需要拆分的种植面。

修正后，两条道路各抽样903 点：T1 最小向上净空约 **10.067 米**，T2 约 **10.011 米**，没有低于本轮9.8 米阈值的样本。最高约60.125 米，未超过原主要地形约60.918 米的高度范围。

这些结果针对生成结构的采样检查，不代表整条道路碰撞验收、完整自交证明或工程结构计算。实体交界、局部覆盖体和支撑间的接缝仍需细化。尚未导入游戏验证。

## 可复现方法

脚本：`tools/rhino_hybrid_solid_terrain_v04.py`。依赖当前 Rhino 会话中的 v02 场地状态，首次运行 `prepare()`、`publish()`，然后执行 `fix_road_outlet()`、`verify()`、`capture()`。备份路径已存在时拒绝覆盖，不能在已发布状态重复发布。

会话命名空间：`scriptcontext.sticky['hybrid_recipe_namespace']`。独立模型归档、隔离视图和保存文件回读结果另记于本目录的 JSON 报告。

方法总则见 [建筑曲面的支撑与衔接](../../../RHINO_CONTINUOUS_ARCHITECTURAL_SURFACES.md)。本轮的局部位置和支脚数量仍是当前方案选择，不作为其他地区的固定模板。
