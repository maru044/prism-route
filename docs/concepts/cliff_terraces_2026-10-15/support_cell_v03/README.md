# 连续支脚—拱腹—顶面：局部形体验证 v03

本轮针对上一版地形曲面像变形板片的问题，只做一个完整局部单元，重点检验底部支柱与上方展开面的连续关系。

方法与适用范围另见 [建筑曲面的支撑与衔接](../../../RHINO_CONTINUOUS_ARCHITECTURAL_SURFACES.md)。本样段包含两根各自独立的单支脚，尚未实现真正的柱身分叉、多层交汇或复杂内部空间。后续按各区域效果图分别设计，不将本单元直接套用到所有构件。

- `05_isolated_underbelly.png`：桥下视角，检查肩部、扭转和两个方向的展开。
- `01_foot_to_belly.png`、`02_under_canopy.png`：在原场景中的低视角检查。

当前 Rhino 的新图层是 `崖岸_连续支柱与拱腹_局部验证_v03`。上一版内退建筑曲面及其种植覆盖层已隐藏，所有对象仍保留；裁切后地形和中央桥仍作为场地上下文显示。尚未把这个样段扩展为整片地形，也未修改中央建筑。

## 建模改变

顶面、卷边、变厚腹部和两根支脚属于同一个连通拓扑。底面中的两个拓扑开口直接延续为支柱的环形截面，支柱与腹部没有作为独立体块进行布尔拼接。

支脚向上展开为约 62–65 米 × 109–110 米的肩部控制范围，向下收束为约 13–14 米 × 14 米的脚部控制范围；两根支柱分别向相反方向偏转，截面逐渐旋转约 28 度。肩部接近屋面时过渡为有厚度的拱腹，前后两侧形成连续悬挑。上述尺寸为控制网的设计尺度，细分后的实际轮廓会略有变化。

顶面有纵向起伏和横向曲率，边缘滚转进入腹部；支脚收口从方形改为圆滑截面，底部封口埋到约 -4 米。样段当前未添加草地、植物或道路覆盖，以便直接审视白色结构。

## 验证与限制

最终控制网为 1,246 个顶点、1,272 个面。控制网闭合且为流形；Rhino SubD 有效、闭合。对细分后的表面网格做连通检查，得到一个连通体。最高约 56.07 米，未超过原场地约 60.918 米的高度范围。原有场景几何 CRC 保持一致。

相关两条中层道路分别进行了 903 个向上射线抽样，本次局部样段没有被这些射线命中，因此不报告新的隧道净空数值。不能将其解释为整条道路的完整通行验收。

已写出独立 3dm，并回读确认一个有效、闭合的 SubD。完整场景另有保存。隔离拍摄只临时隐藏背景对象，随后恢复其可见性。

本轮是形体和拓扑验证，不是结构计算、全域自交证明或游戏碰撞验收。与原地形的边界拼接、整片支撑体系、种植区和实际道路关系仍需下一阶段设计。尚未导出游戏资产。

## 可复现脚本

`tools/rhino_continuous_support_cell_v03.py`。

在保留内退方案场地状态的 Rhino 会话中，以 UTF-8 读取执行。首次使用 `build()`、`publish()`；修改样段参数后使用 `refine()` 更新本脚本拥有的单个对象。`verify()` 检查闭合、连通、高度及原几何；`capture()` 和 `archive_and_capture_isolated()` 保存视图和独立原生模型。

本次会话保留 `scriptcontext.sticky['support_cell_namespace']`。重新打开文件后的状态恢复尚未自动化，不应在已存在样段时重复发布。
