# 道路入口外露曲面支撑：方法参考

历史样段日期：2026-10-15；整理日期：2026-10-18。现用场景见 [当前建模入口](../../../CURRENT_MODEL.md)。历史全场副本、重复归档和逐次检查数据已删除。

方法是在实际三维道路穿越的位置局部退让底层实体，保留普通实体段，把支脚、肩部、拱腹和顶面组织为连续 SubD。前后结构采用不同高度，并留出有用途的侧向开敞。不能把造型支撑藏进实心墙里，也不能在远离道路的位置任意开廊。

道路适配时，使用实际路面与所需净空切割成品 Brep；未切割的 SubD 只作为编辑源。现用文件中，成品位于“地形::入口曲面与支撑”，四个编辑源位于隐藏的“参考::SubD编辑源”。旧的暂定种植覆盖副本已经清理。
