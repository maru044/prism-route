# A1 双层桥：实际 Rhino 模型

2026-10-20，已写入 `D:/Prism Route/map/map_current.3dm`。本目录的 `model_*.png` 是实际 Rhino 截图；前一目录的 A1 图片为设计效果图。

双层约 20 m 宽道路跨越约 126.79 m 的缺口，上下相差约 25 m。分别读取两层既有道路端点、方向、宽度和横坡，用独立三次曲线连接；两层中心线保持各自的位置，外侧壳体预留横向余量。

两侧斜壳方向相反，各有两个不等大的眼形开口。外皮、内皮、洞口回转面和上下桥腹接为一个 12 面的闭合 NURBS 实体；桥腹直接从斜壳的内侧边界跨接，没有在壳体内部保留单独搭接的桥板实体。洞口在厚度方向回转，内外轮廓不同。靠道路内侧的板墙转角有意保留，未宣称整座桥所有接缝均为 G1。

只新增三个对象，复用 `交通::中层道路` 和现有材质，没有新增图层或独立 CAD 副本：

验证记录见 [validation.json](validation.json)：

- 桥体有效、闭合、流形、单连通，无裸边；12 个底层曲面均为原生 NURBS，没有通过 SubD 转换取得。
- 斜壳与开口回转面的接缝抽样 180 点，最大法线夹角约 0.0154°，对应曲面间最大位置误差约 0.000753 m。
- 两层各 505 条向下射线均命中桥腹。下层路面下方支承间距约 0.095–0.108 m，上层约 0.031–0.211 m；分别采用 0.16 / 0.28 m 铺装厚度，确保铺装底部嵌入桥腹。
- 下层抽样最小顶空约 19.899 m；上层抽样上方没有新桥体。邻近既有结构对上下层各 303 条路面以上 0.15–6 m 竖线均无命中。
- 原有 225 个对象几何 CRC 未变，包括开放隧道、底板和竖直岸墙。保存后重新读取主文件，全部 228 个对象编号和几何 CRC 一致；现用图层保持 26 个。

这些是局部抽样、拓扑和视觉检查，不是全场精确干涉、Godot 驾驶碰撞或工程承载验收。植物、旧化和最终灯光尚未制作。
