### 建模方法与限制

- 重新查看 A 效果图，以宽的连续地形顶部为目标。
- C1 为长 S 高边，C3 为短弧高边。直接按等参数放样会翻折，因此采用共同约束的原生 NURBS Patch，并在两端添加不穿越 S 边界的收口曲线。收口属于本次设计选择，仍可修改。

- 成品为有效、闭合、朝外、六面 NURBS Brep。道路中心采样没有发现进入本主体的点；这是草稿检查，不等于完整车道与车辆净空验证。
