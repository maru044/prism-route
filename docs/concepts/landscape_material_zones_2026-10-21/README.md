# 全岛景观材质分区概念（2026-10-21）

用户要求基于扎哈式景观流线，为大的空白顶面提供建筑遗迹材质与植物材质分区效果图，详细但不杂乱。

`landscape_material_overview.png` 使用内置 imagegen，以用户当前总览 `site_reference.png` 为参考生成；最终提示词见 `prompt.md`。这是设计概念，非 Rhino 或游戏实景截图。本次没有改动 CAD 几何、已绘制的两条遮罩曲线、游戏材质或遮罩资源。

## 分区构想

- 大片草地和低灌木作为种植底色，用少量连续、变宽的浅色遗迹铺面串联既有道路、桥头与平台入口。主要路径在少数节点展开为留白广场。
- 各大平台以几组顺应岸线和交通走向的长曲线组织，减少小碎块；树群集中在少数入口、宽平台与停留节点。
- 下方中央马蹄形大岛保留，屋顶以种植为主、窄建筑边缘带和一条主流线联系椭圆顶盖；内侧阶梯平台延续种植。
- 建筑遗迹通过暖白石材、风化接缝、少量裂纹和缝隙植物表达。保持垂直墙体、桥腹和道路可辨。

生成图总体沿用原场地轮廓、泻湖、道路、中央大岛及桥梁布局，但生成式细节、环塔比例与局部边界并非 CAD 几何的精确复现。图中区域不能直接用作尺寸精确的遮罩；如用户选定设计方向，需在现有 CAD 顶面上重新绘制主曲线并读取实际源对象与高度。
