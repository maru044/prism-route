## 本轮设计

实际裁掉原主要顶面约 491,582 平方米的设计区域，再用有纵向起伏和横向扭转的暖白建筑壳体替换。两条曲面带位于标注弧线的陆侧，并裁切到原顶面的平面轮廓内；两侧宽体块内切，中部因原本连接很窄，以独立的悬跨桥身连接。

中央桥沿实际道路曲线构建，保留路面、两端接点和标高。桥身横向宽度变化，白色边缘下卷，下面形成大跨度开口和落地支承。中层道路的实际三维曲线用于隧道预留，采用布尔裁切净空体。

新种植顶面为独立、可编辑 NURBS 面，沿白色曲面保留边缘；目前仅为区域设计，未摆放实际树木或草实例。已纠正内退后顶面法向，并为新壳体与种植面设置较细的 Rhino 显示网格。与新顶面重叠的旧丘陵仅裁掉设计区域内部分，设计区域外仍保留。

## 检查结果和范围

新建筑壳体及桥身为有效闭合 Brep；其他保留地形与种植面按原用途仍为开放曲面。相关原始对象的几何 CRC 保持一致。

整体未超过原主要地形约 60.918 米的高度范围，新造型主体控制在约 60 米高度。两条中层道路各抽样 903 点，在生成建筑壳体及桥身上的最小向上净空约为 T1 11.737 米、T2 10.081 米，均没有低于本轮 9.8 米检查阈值的样本。

这些是设计阶段的部分抽样，不代表完整碰撞验收或结构设计。原地形与新壳体的局部接缝、端部衔接及原有道路穿地仍需继续细化。尚未导出游戏资产，也未进行游戏内通行验证。

## 可复现编辑

脚本：`tools/rhino_terrace_inset_v02.py`。在 Rhino 使用 UTF-8 读取并执行，顺序为 `prepare()`、`publish()`、`finish_display()`、`refine_overlap()`、`verify()`、`capture()`。首次发布拒绝覆盖已有备份，已发布状态不应重复运行 `prepare/publish`。

当前 Rhino 会话还保留 `scriptcontext.sticky['inset_recipe_namespace']`。可用其中的 `switch_variant(inset=True/False)` 切换两种完整方案，同时恢复对应的共享原始地形。仅手动切换两个根图层不足以切换共享地形，查看单独保存的完整 3dm 更直接。
