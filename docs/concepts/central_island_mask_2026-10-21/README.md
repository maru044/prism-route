## 后续生成遮罩时读取

曲线为闭合区域边界，不是有带宽的开放中心线。关键用户文本：

- `mask_source_object_id` / `mask_source_face_index`：明确所属源对象和顶面（索引 3）。
- `mask_inside=planting`：线内种植。
- `mask_between_curve_and_source_top_edge=architecture`：仅源顶面边缘带为建筑。
- `mask_terrace_platform_default=planting`：该岛阶梯平台为种植，不能把上层轮廓以外的所有平台都判成建筑。
- `mask_surface_z_m` / `mask_display_lift_m`：实际高程与显示抬高量。

后续按源对象和高度限定投射范围；不能将高处椭圆顶盖的遮罩直接穿透投到下方顶面。原 `参考::种植边界` 的六条曲线不变。先前导出器只支持开放中心线，现已按用户后续要求增加闭环恒宽支持；原始边界仍在独立图层，目标图层中是另行移动半带宽后的建筑中线，不能把两类曲线混为相同位置和语义。
