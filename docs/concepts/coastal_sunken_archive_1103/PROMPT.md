# 概念图生成记录

工具：内置 image_gen；模式：带场地参考的概念生成。

输入：`site_reference.png`，用户标出的前景沿岸圆形凹槽。红圈只作定位。

输出：`concept_v01.png`。本图为 AI 概念图，不是 Rhino 模型或 Godot 实机截图。
