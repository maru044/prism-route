## 设计方向

沿用项目的暖白连续曲面、低饱和蓝灰玻璃、局部耐候金属、少量风化和自然重新占据的植被。建筑以低矮、半地下的环形公共空间为主；“档案馆”是建议的空间用途，当前不增加功能设备或室内陈设。

保留原凹槽的碗状读法，主体沿凹槽外围嵌入地形，中央留出露天采光庭院。地表只露出低矮弧形屋顶与入口。道路侧设置可识别的步行接入，再以弧形楼梯和平台下到主要环廊。局部屋面缺损，暴露有限的梁架，形成阳光进入内部的焦点。

以一层主要地下空间为目标，保留可达的庭院、内向环廊和少数侧厅；采光来自中庭及屋面缺口。临海侧保持连续围护，不再预留第二层和海向开口。

## 建模前必须落实的场地关系

截图不能证明真实尺寸、朝向、高程或地形厚度。需要在当前 `D:/Prism Route/map/map_current.3dm` 中定位并读取：

1. 凹槽边缘轮廓、最低点和坡壁范围；确认是单一地形还是多个已有实体叠合。
2. 道路边缘与场地之间的实际水平距离、高差和可用接入宽度。
3. 主要地坪、地形底面与临海外壁剩余厚度；确认地下空间被地形包容，临海挡墙完整保留。
4. 已有路径和邻近建筑的可见关系；新屋顶控制在凹槽周边的地形轮廓内。

概念图的楼梯数量、缺损边缘和剖面构造不是实测数据。临海低层已经取消；下一版参考需要压低屋面、封闭海侧，再作为固定视角对照依据。

## 建议实施顺序

1. **场地测量**：记录对象编号、边缘和道路/海面高程，画平面与简单剖面，确定这一处的可用范围。
2. **空间白模**：先制作入口平台、下行楼梯、庭院地坪、环廊与挡墙；从玩家高度验证进入、转向和视线，海侧保持封闭。
3. **结构与破损**：沿现有曲面语言建立有厚度的屋面和内外墙，再落实局部缺损与梁架；完整区和破损区非对称分布。
4. **材质与环境**：复用项目暖白建筑、金属和蓝灰玻璃材质，在接缝、屋面边缘与庭院局部安排植被，保留大面积清晰表面。
5. **Godot 验证**：通过已建立的局部资产流程同步，检查楼梯/边缘碰撞、地下采光、入口可读性和海侧低视角轮廓。

当前只记录提案，具体尺寸和与原地形的接合方式待实测落实。最新高度控制、构件拆分、固定视角和分阶段美术门槛见 [详细计划](BUILD_PLAN.md)。
