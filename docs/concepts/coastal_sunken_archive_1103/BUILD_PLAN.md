## 2. 场地与高度怎么控制

首先定位原地形物件，记录编号、层级、几何 CRC、轮廓和至少两条穿过庭院/道路方向的剖面。剖面必须包含地形上下表面、道路路面及临海外壁，确认实际可以容纳的内部空间。

**地表基准**取未修改的凹槽口周缘地形及其自然延续趋势。开口处用周缘标高建立参考包络，不把凹槽底当作地表基准，也不通过整体抬高周边土层满足埋入效果。

建议的初始高度控制：

| 项目 | 拟议控制值/判据 |
| --- | --- |
| 大部分屋面与外侧收边 | 贴近参考地形，主要实体尽量位于包络以下；常规外露约 0–0.3 m |
| 必要的局部混凝土收口 | 暂以高出参考包络不超过约 0.6 m 为目标；连续超出段必须重新调整 |
| 入口 | 采用向凹槽内下切的入口，门洞和主要室内净高放到地表以下 |
| 安全护栏 | 按实际落差另行设置，使用轻薄构件；不计入屋面实体高度，但需要检查远景轮廓 |
| 一层主廊/侧厅净高 | 初拟约 3.5–4.5 m，依原地形厚度和空间感调整 |

沿外侧收边取样比较新屋面与参考包络；低视角再检查连续轮廓。若地形厚度不足，先缩小埋入范围、收紧侧厅或调整地坪，再评估方案；不增加临海层，也不靠整体抬高建筑解决。

## 3. 模型分成哪些部分

| 构件 | 造型与实现重点 |
| --- | --- |
| 地形接口与挡土围护 | 只对实际占用区做局部让位，外侧连续埋入原坡面；记录开挖范围，避免重叠地形遮住廊道 |
| 中庭地坪与主环廊 | 一个主要地坪层，庭院略偏心；环廊宽度有变化，完整通行路线围绕采光口展开 |
| 道路侧入口与弧形阶梯 | 路肩接入平台、入口缺口、楼梯、落地平台连续衔接；入口从道路步行视角可识别 |
| 内向墙体与少数侧厅 | 门洞有深度和墙厚，侧厅朝庭院开口；取消海向贯穿空间 |
| 低伏曲面屋面 | 先定外缘、内檐及关键截面，再建立有厚薄变化的壳体；外缘接地，内檐向庭院展开 |
| 局部缺损与梁架 | 在一个非对称区集中表现，缺损屋面、残留边缘和实际梁跨成套设计 |
| 玻璃、栏杆与收边 | 在主形体成立后加入，优先复用现有材料，构件比例服从玩家距离 |
| 接缝、旧化与植物 | 以入口、缺口、排水路径和接地处为重点，保留清楚的大面与通行空间 |

墙、地坪、台阶、层板优先用可编辑的 NURBS/Brep 实体。屋面使用少量有明确截面控制的 NURBS 面，确有连续转折需要时再用 SubD。实体闭合之外，还要检查檐口曲率、屋底厚度、墙顶衔接和视觉上的承托关系。

构件按用途组织在同一个建筑组中；阶段修改替换对应构件，使用一个局部回退点，不把多版方案长期叠加到主场景。

## 4. 先锁定的视觉特征

1. **从外看低伏，从内看开敞。** 道路和岸线远景中，主体隐在凹槽里；走到入口才逐步看见下沉空间。
2. **庭院和阴影环廊构成一明一暗。** 内部必须有真实深度，庭院开口足够宽，屋顶保持遮蔽感。
3. **曲面转折有完整截面。** 屋面由接地端逐步进入内檐和底面，厚度与边缘圆转共同形成轮廓。
4. **入口和破损位置不对称。** 一段宽弧形楼梯组织主要进入方向；另一侧以缺损屋面及少量裸露梁形成视觉焦点。
5. **废弃感有主次。** 大结构仍然清楚，旧化与植物集中在有理由的位置，主地坪与关键视线保持可读。

庭院净短轴可先按可用建筑短轴的约 60–70%探索，最终以场地和修订参考为准。此比例只是白模起点，不能机械地将原凹槽替换成标准圆柱或所有宽度一致的圆环。

## 5. 美术验收表

| 验收项 | 怎么检查 | 需要达到的表现 |
| --- | --- | --- |
| 场地轮廓与高度 | 固定道路视角、岸线低视角，叠看原地形轮廓；检查屋面高度取样 | 原坡面走势继续成立，屋面低伏；临海侧保持封闭，无新增低层或突出体 |
| 庭院比例与空间留白 | 鸟瞰和平面，同时隐藏植物、玻璃、旧化 | 庭院、环廊、入口有主次，开口形状与修订参考接近，不被构件塞满 |
| 曲面语言与厚度 | 近景看内檐、外缘、屋底；用斑马纹/反射条检查关键过渡 | 关键转折平顺，厚薄变化有意图；边缘没有波浪、尖刺、夹点或悬浮拼接 |
| 入口与楼梯构图 | 从路肩、人眼高度和庭院回望入口 | 一眼能判断进入方向，台阶与平台落点成立，入口保持地下建筑的下切感 |
| 破损的整体构图 | 固定鸟瞰与庭院机位看完整区/缺损区对比 | 一个主要破损区清楚可辨，露梁真实跨接，缺损不是沿整圈均匀复制 |
| 梁柱与檐口比例 | 以角色尺度检查遮挡、梁下净空与落地 | 结构有厚度和承托感，构件不抢占庭院，也不显得像细线或装饰贴片 |
| 材质层次 | 相同日照与曝光下检查暖白实体、蓝灰玻璃、暗金属 | 主体暖白、阴影有层次、玻璃与开口可区分；曲面细节在正常距离可读 |
| 旧化和植被分布 | 远景看色块、近景看接缝与边缘；比较开/关旧化 | 边缘、缺口和接地处较明显，大面有留白，主要路线可辨 |
| 地下采光与画面一致性 | Godot 正常相机、正常曝光，在庭院及廊道各取固定图 | 明亮庭院与阴影环廊同时可读，空间层次接近修订参考；无大面积漏光或黑块吞没空间 |

**几何通过和美术通过分别记录。** 闭合、无自交、无悬空等检查不能代替同机位看起来是否成立。白模的轮廓、比例或截面不符合时先改形体，再推进材质细节。

## 6. 固定相机与阶段产物

固定六个检查视角，名称和相机参数随资产保存，阶段之间沿用：

1. **场地鸟瞰**：对应圈选参考，检查原道路、凹槽、外缘关系。
2. **道路步行视角**：约人眼高度，检查地表突出量及入口辨识度。
3. **入口下行视角**：看庭院显露、阶梯和落地平台。
4. **庭院中心回望**：同时看到内檐、阴影廊道、入口和露梁区。
5. **环廊内部视角**：看庭院采光、门洞深度和顶板厚度。
6. **海侧低视角**：只检查原岸线、封闭外壁和屋顶隐入程度。

另存两条设计剖面做高度和厚度检查。美术对照固定相机位置、投影/FOV、光照方向和曝光；Godot 最终检查沿用实际玩家相机。每阶段保存实际模型截图，清楚区分 AI 概念图与实机结果。

| 阶段 | 必须产生的可审阅结果 | 推进条件 |
| --- | --- | --- |
| A 场地与修订设计 | 可靠定位、实测平面/剖面、低伏封海版本参考、构件范围 | 地形容纳、入口高差和高度包络明确 |
| B 空间白模 | 地坪、墙体、低伏屋面、楼梯；六视角及剖面 | 低伏轮廓、庭院比例、主要空间和通行路线成立 |
| C 曲面与破损 | 有厚度的成品壳体、檐口过渡、主要缺损及梁架 | 形体与修订参考对照成立，关键过渡没有明显视觉缺陷 |
| D 材质与局部环境 | 实际建筑材质、少量玻璃/金属、必要旧化植被 | 材质和植被支持建筑主次，正常日照下空间可读 |
| E Godot 局部验证 | 正式着色下六视角、可行走路线与碰撞/采光记录 | 玩家能进入并返回，楼梯与门洞无阻挡，室内无明显漏光，实机形体达到预期 |

## 7. 防止效果图与模型偏离的执行原则

- 先把用户最新约束落实到参考和剖面，临海层从制作输入中正式删除。
- 先做一个包含入口、内檐、廊道和露梁区的关键样段，确认曲面和构件比例，再扩展剩余部分。
- 每阶段使用固定视角对照轮廓、开口边界、地坪高度及破损区；记录为了真实地形发生的设计调整。
- 零散细节和材质不能作为形体未完成的替代品；重要差异在白模阶段解决。
- 出现厚度或高差冲突时，收紧空间规模与局部范围；继续遵守低伏、单层和海侧封闭的约束。

本阶段交付的是建模计划与美术验收标准。下一步首先完成 A 阶段的可靠场地测量及修订参考，随后才能按上述标准制作白模。
