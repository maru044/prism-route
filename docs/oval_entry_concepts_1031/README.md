## 现有场地实测

- 椭圆基座外轮廓约 168 × 111.6 m，中心 CAD (1086.01, 302.52)。
- 周边屋顶 Z=63.0 m，椭圆顶部 Z=72.6 m，高差 9.6 m。
- 最近中层道路路面 Z=35.0 m，最近路缘约 CAD (1025.99, 369.77, 35.0)，位于椭圆西北侧。
- 从椭圆外边界到上述路缘，沿此方向的水平连接约 26 m。这是出口概念长度，正式开洞前还需确定外墙厚度与道路肩线。

## 拟议空间与路线

保留现有椭圆体量作为入口斜肩与环形边缘，拟将中央约 110 × 66 m 区域打开，形成贯穿到中层的采光中庭；该开口尺寸是设计建议，并非现状测量。

外部以约 8 m 宽的分段弧形台阶由屋顶登至 +72.6 m。玩家从明确的入口缺口跳至 +69.8 m 的宽平台。内部为围绕大中庭错位布置的残存弧形廊台、短旋转楼梯与预留侧厅，沿途可看见下一段落点。

| 顺序 | 通行关系 | 高程 / m |
| --- | --- | --- |
| 入口 | 外部台阶登高 | 63.0 → 72.6 |
| 第一次下落 | 从入口缺口跳入第一廊台 | 72.6 → 69.8 |
| 上段 | 弧形廊台与旋转楼梯 | 69.8 → 60.6 |
| 第二次下落 | 楼梯末端断开，落到下一廊台 | 60.6 → 57.8 |
| 中段 | 错位廊台与另一段旋转楼梯 | 57.8 → 48.6 |
| 第三次下落 | 再次通过断差进入下段 | 48.6 → 45.8 |
| 下段 | 最后一段旋转楼梯 | 45.8 → 35.0 |
| 出口 | 水平短通道接中层道路路肩 | 35.0 → 35.0 |

三处下落断差均暂定 2.8 m。当前角色原地跳跃理论顶点约为 7²/(2×22)=1.11 m，因此这种高差具备阻止原路跳回的条件；正式建模后需验证跑跳、碰撞、边缘与周边可踩物，不把效果图当作碰撞验收。上下落点留充足承接平台，不让玩家靠猜测跨越无底洞。中层出口同高接路，不降到水边或底层步道。

各段不是一条可连续逆行的完整旋转楼梯：短楼梯只处理本段内的下降，段与段之间由明确断差隔开。也不采用逐层封满的圆盘楼板，而是旋转错位的部分弧形平台，保持中庭通透与路线可读。

## 美术与建模约束

沿用近未来、自然夺回废墟的主题：暖白曲面预制板、轻型金属支承、少量蓝灰玻璃、局部脱落面板与从采光口进入的植物。保留宽阔空平台和侧厅，目前不指定角色、打印台或道具，不增加神像或古代神殿元素。
