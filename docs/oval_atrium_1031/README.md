主文件：`D:/Prism Route/map/map_current.3dm`。图层：`建筑::椭圆下行中庭`。

当前版本已接入 F5 主场景 `scenes/map_1021.tscn`，采用四段连续坡道，包含外部登高坡道和三段内部下降坡道。可见坡道本身生成碰撞；旧台阶、楼梯护栏及四块独立平滑碰撞面已移除。

内部沿墙通路保留，平台内缘改为不同宽度的弧形挑台。中部增加两组、共六块错位落台，相邻高度差为 3 米，形成可直接下跳的捷径。落台平面相互重叠，重叠处净高约 2.35 米。角色实机跳落体验在导入阶段再验证。

底部中央保留不规则草地覆盖面及周围硬质通路。按实际开口、外壳、入口坡道和出口范围清除 105 棵原有树木，仅追加对应删除记录；当时的 174 条手工调整记录全部保留。内部树木、灌木由用户在 F4 编辑模式下自行摆放。

底部草地已按后续要求替换：移除原 `grass_ground_albedo.png` 重复纹理，改用大世界同一 `landscape.gdshader` 的绿色单色底面，复用 `meadow_palette.gd` 中的近地 `#71944b`、远景 `#69af3f`，关闭该底面的细节纹理变化。草使用现有 `grass_star_3card_v6.glb`、同一个运行时草材质与风／交互／LOD，局部指定绿色色板 `#73a448`，不改变其他区域的绿黄分布。

新增 15 个局部烘焙格的独立覆盖缓存，其中 13 格含中庭草，约 125292 株；数据保存在 `assets/world/oval_atrium_1031/grass_bake/`，通过同一流式加载器读取。全地图基准缓存不重写、不失效；局部格按真实碰撞与 0.65 米边缘退距采样，避免长到硬质通路上。此次用户保存的 217 条树木调整记录未修改。

出口与地表修订：草地改为贯穿底板厚度的嵌入区域，顶面与地板同为 35 米，底板在草地范围内实际开孔；不再把薄贴片叠在底板上。道路连接板也裁去了室内重叠部分，并移除冗余的底层落地板。最后一段坡道及其上游平台沿椭圆退开 25°，坡道先落到出口右后方的空地，门洞前保留平坦通路。

连接桥交界微调：桥面按现有道路实体的曲线边界裁去重叠部分，两侧护栏和支撑末端随之收回。原道路、树木及内部布局不变，已同步游戏资源；按用户要求未重跑完整验证。`bridge_join_fix.json` 记录此次三个局部对象的修改，前述实机报告对应此次微调之前的检查。

尺度保持当前版本：上部开口 **110 × 66 米**，外部椭圆轮廓 **168 × 111.6 米**。屋顶标高 63 米，入口环沿 72.6 米，底层及道路出口 35 米。出口与现有中层道路同高。

## 检查

F5 启动后，下拉定位点选择“椭圆中庭 · 屋顶入口”或“椭圆中庭 · 底层出口”。也可运行 `tools/run_oval_atrium_1031.ps1` 直接以自由镜头预览中庭。

游戏模型为 `assets/world/oval_atrium_1031/atrium.glb`：29 个中庭对象与 3 个挖空后的岛体／屋盖替换对象。加载时移除基础地图内对应的三块旧实体及其碰撞，再加载经检查的替换对象；基础地图 GLB、基准树位、原草地缓存和其他建筑资产保持不变。材质使用原建筑／地形材质及中庭 PBR 参数，草地保留导出的 UV。

`game/headless_report.json` 记录了完整主场景的物理检查：404 个坡道采样点、四段角色行走以及出口至中层道路全部通过，行走时失去地面支撑的帧数均为零。`game/game_report.json` 与 `game/overview.png`、`game/interior.png` 来自同一主场景的 D3D12 实机渲染。`game/tree_cleanup.json` 记录清除的树木编号。
