# Cliff B 西端圆润轮廓修正

2026-10-13。修正上一版 NURBS 台地西端屋盖被退让挤成尖头的问题。

原退让主要为 45 米，屋盖再叠加 3.8 米斜切边。局部最小曲率半径约 33 米，统一退让会显著压缩这个端部。此次保留其他部分的退台方案，仅在源轮廓采样索引 120–355 范围内，通过平滑权重过渡，将核心段退让控制为 `min(8 米, 局部曲率半径 × 0.15)`；屋盖保留斜切收边。顶部恢复较宽的弧形轮廓，并从标高 43 米开始增加斜向肩部体量，连接下层台地与顶部。

`before.png` 与 `after.png` 是相同视角、相同显示方式下的真实 Rhino 截图。前者使用生成前备份中的原实体，后者使用安装后的模型。

当前实体侧由三个闭合、有效的原生 NURBS 多重曲面组成：保留台地内核、局部肩部、修正屋盖。肩部与内核采用埋入式搭接；屋盖底面埋入标高 57 米交接面下 0.2 米，接缝处没有外露的重合顶面。这一版本没有强行合成单个实体：Rhino 的布尔合并曾丢弃新增肩部体量，不能以返回一个有效实体就判定轮廓修正成功。后续制作最终单一外皮或游戏碰撞时，仍需处理这些体块内部的搭接面。

验证：

- 三个组成体均有效、闭合，边线自交检查为零。
- 每个组成体分别进行 BVH 三角形穿插检查，均未发现非相邻、非共面的三角形交叉；不覆盖共面重合或不同组成体之间的设计搭接。
- 全部组成体一起检查，与七组周围地形、岛屿墙体无相交。
- 道路通行体积、九处底层通行测试无相交。
- 七组原墙体和四块原邻岛顶面与修正前备份的原生几何比较一致。
