# 标题界面制作指南

F5 打开 [标题场景](../scenes/ui/title_screen.tscn)，「开始游戏」加载正式世界。「设置」打开 API 连接页，自由对话和游戏助手各有独立配置。勾选「在本机记住密钥」时，密钥随现有配置文件保存。临时密钥可以从标题界面传到本次游戏进程中的聊天面板。

[Blender 源文件](../assets/title/source/title_coast.blend)包含金色草坡、礁岸、断环、台地、树位、相机和荧的站位与朝向目标。两处开孔贯穿断环。Blender 源文件可直接编辑，再用 glTF 2.0 导出并启用 Cameras。也可以从项目根目录重建初始版本。

```powershell
& 'D:\blender\blender.exe' --background --python-exit-code 1 --python tools/blender/build_title_coast.py
```

Godot 复用正式世界的天空、海面与近景草材质。标题页单独校准草的麦金色、草根明度和地面底色。每格沿用 24 米、5,200 次取样和每个根点四株的规则，按地面材质跳过步道。仅在标题页把草的实例高度缩到 46%。遗迹周围布置 5 棵红橙色大阔叶树与 7 棵边缘绿色小阔叶树。树位由 Blender 保存，树冠、树干、着色器和配色复用正式世界资源。距离变化时继续使用原始树网格。

荧由大世界玩家控制器加载，使用正式待机 `motion_review/A01.tres`、MToon 和 VRM 弹簧骨。标题相机沿用玩家相机的 55° 视野，眼高由荧的相机支点、俯仰和默认弹簧臂计算。标题构图的水平位置与朝向在 Blender 中调整。

海面使用天空反射模式，直接读取标题天空的显示贴图，采样经度叠加天空的显示偏航。倒影使用天空亮度的 90%，在海平线保留轻微明暗差。海浪循环播放，海鸥声按间隔从大世界的四段音频中选取。手绘标题为透明贴图，按钮使用[项目 UI 风格](UI_STYLE_GUIDE.md)的淡蓝纸面。
