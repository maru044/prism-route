# 标题界面制作指南

F5 打开 [标题场景](../scenes/ui/title_screen.tscn)，「开始游戏」加载正式世界。「设置」与游戏内 Esc 共用画质和声音选项。「API 配置」为自由对话和游戏助手分别设置接口。「API 基础地址」可以直接粘贴酒馆的自定义 OpenAI 端点。填 `https://服务域名` 时，游戏访问 `/models` 和 `/chat/completions`。服务商的基础地址带 `/v1` 或其他路径时，把它一起填入。已保存的完整 `/chat/completions` 地址仍可使用，本机回环服务也可填写 HTTP 地址。

填写地址和密钥后，点击「获取模型」会请求该 API 基础地址下的 `/models`，下拉列表使用服务商返回的原始模型 ID。服务商未开放模型列表时，可手动填写 ID。选择模型后点击「保存」，当前入口的地址、模型 ID 和密钥一并写入本机 `user://llm_client.cfg`，重新启动游戏后仍可使用。

点「开始游戏」后显示 Archaea Studio 加载画面。角色两侧的气泡以 7 帧每秒循环播放五帧，右上角「加载中」按透明度渐亮渐暗。[加载脚本](../scripts/ui/title_loading.gd)在后台读取正式场景及主地图模型，遮罩跨过场景切换，等大世界初始化完成后再揭开。正式入口的默认出生点是「南部 · 初始洞穴」。PNG 底图和气泡图集放在 `assets/title/`。

游戏中按 Esc 可保存到三个手动槽位，也可以读取手动或自动存档。「继续游戏」读取最新有效存档。家园编辑和教程进度更新自动存档。关闭窗口或从设置退出时，可选择保存并退出、不保存退出或取消。保存并退出写入自动槽。

存档位于 `user://saves/`。每个槽位同时记录主控角色与位置、世界进度、两个家园以及两种对话的历史和草稿。仍在生成的回复会中断，重新进入世界时从可站立的探索位置恢复。模型配置、游戏设置和实时对话标签在各自的入口管理。加载时会在主文件损坏时尝试同槽位的上一份备份。

新系统通过 [存档会话](../scripts/progress/game_save_session.gd)的 `register_section()` 注册自己的状态快照，再在适当的初始化阶段调用 `read_section()` 恢复。已经存在的其他状态分区随存档保留。

[Blender 源文件](../assets/title/source/title_coast.blend)包含金色草坡、礁岸、断环、台地、树位、相机和荧的站位与朝向目标。两处开孔贯穿断环。Blender 源文件可直接编辑，再用 glTF 2.0 导出并启用 Cameras。也可以从项目根目录重建初始版本。

```powershell
& 'D:\blender\blender.exe' --background --python-exit-code 1 --python tools/blender/build_title_coast.py
```

Godot 复用正式世界的天空、海面与近景草材质。标题页单独校准草的麦金色、草根明度和地面底色。每格沿用 24 米、5,200 次取样和每个根点四株的规则，按地面材质跳过步道。仅在标题页把草的实例高度缩到 46%。遗迹周围布置 5 棵红橙色大阔叶树与 7 棵边缘绿色小阔叶树。树位由 Blender 保存，树冠、树干、着色器和配色复用正式世界资源。距离变化时继续使用原始树网格。

荧由大世界玩家控制器加载，使用正式待机 `motion_review/A01.tres`、MToon 和 VRM 弹簧骨。标题相机沿用玩家相机的 55° 视野，眼高由荧的相机支点、俯仰和默认弹簧臂计算。标题构图的水平位置与朝向在 Blender 中调整。

海面使用天空反射模式，直接读取标题天空的显示贴图，采样经度叠加天空的显示偏航。倒影使用天空亮度的 90%，在海平线保留轻微明暗差。海浪循环播放，海鸥声按间隔从大世界的四段音频中选取。手绘标题为透明贴图，按钮使用[项目 UI 风格](UI_STYLE_GUIDE.md)的淡蓝纸面。
