## 4. 需要收紧的技术表述

### “无 missing controls”不等于完整骨骼和效果全覆盖

静态检查通过的是必要主干/肢体控制骨，不包含所有模型专有骨、局部形变和 Morph。本次 13 个目录均至少有一份人体轨道使用了非零 Morph；部分还包含参考骨架未映射的动态模型专有骨。

现有共享层主要验证身体姿态、骨长保持、位移、时钟和可选扭转辅助骨；没有实现全库 Morph、全部自定义形变或所有角色物理。README 中对完整表现的期待可保留为制作目标，但不能写成现有转换器已经完整支持。

建议把相关技术判断理解为：

> 当前参考骨架的必要控制骨名称检查通过，可进入身体动画试跑；模型专有骨、Morph、支撑物、循环及接触仍需按用途验收。

### 循环、通用性和制作成本尚不是逐组已验证结论

“无缝循环”“稳定性极高”“所有角色完美复用”“重定向难度极低”等表述，目前缺少这些具体源组的共享转换与接缝报告。11 组 KEEP 中，只有 Loop 03 已有本项目共享身体动画的实测基线；其余 10 组尚未因此次选片而自动完成移植。

“全库唯一”等稀缺性描述按用户的人工选片判断保留，本次未用文件名扫描独立证明内容上的唯一性。

### 多人和道具是独立制作条件

选片器有第三槽位，验证场景也能加载多个角色实例；这不等于 Loop 27 的实际三轨演出已通过最终测试。它应作为独立的多人验收项，不能沿用 Loop 03 双人的通过结论。

椅子、床、沙发等支撑与角色放置，以及具体角色体型的适配，也不是共享身体资源自动附带的结果。轻微穿插可按用户既定标准接受，但仍应区分“允许的画面偏差”和“必要的角色或支撑缺失”。
