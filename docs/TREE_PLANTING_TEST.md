# 游戏内树木种植测试

**2026-10-30 更新：植物编辑已合入正式 F5 大世界，使用 F4 或「植物编辑」按钮切换。原 `tree_planting_test.tscn` 现在也打开同一个正式世界。当前使用方法与保存位置见 [正式植物编辑说明](world_planting_1030/README.md)。下文是早期独立测试工具的历史说明，仅用于旧数据存储回归夹具。**
运行后直接使用左侧面板与场景交互。无需编辑器插件，也无需修改 Godot 引擎。
编辑器的 3D 视图只保留场景入口，地形、树木和操作面板在运行时载入。
F5 仍运行正式的 `map_1021.tscn`。

## 操作

1. 运行后自动定位南部屋顶，显示附近最多 40 棵树。区域菜单可切换南北与各高度；
   “载入区域并定位”切换区域并移动镜头。“载入镜头中心附近”从当前镜头朝向查询地形。
2. **选择**模式：左键点击树冠。脚下青色标记表示选中树；点空处取消选择。
   “定位”将镜头移到选中树旁；未选择时返回当前区域。
3. **移动**模式：先选树，再点击目标地面，将树根移到该位置。
   面板的 X、高度 Y、Z、旋转和大小可精确调整；只支持绕 Y 轴旋转与均匀正值缩放。
4. **新增**模式：选择树种和颜色，在可种植地面连续点选新增。
   新增后的树会自动选中。切换到“选择”或按 Esc 结束新增。
5. “应用树种 / 颜色”修改选中树。“复制”生成副本后进入移动模式，点击地面放置。
   “删除”移除选中树。
6. “贴地”只查询树根上方 2 米到下方 6 米之间的地面，避免跳到其他楼层。
   道路、水面、沙滩和陡面不能直接点击种树。跨层时可直接点击目标顶面移动/新增。
7. 面板按钮或 **Ctrl+Z / Ctrl+Y** 撤销与重做，保留最近 100 次本区域操作。
   切区保留修改，但清空本区域撤销历史。
8. **保存测试布局**才会写入磁盘。窗口关闭时若有未保存改动，会提示保存、放弃或继续。
   Godot 的停止运行按钮会直接结束进程，停止前须先保存。

镜头：右键拖动转向；按住右键 + WASD 移动、Q/E 升降，Shift 加速；滚轮前后移动。
在面板编辑数字时不会触发镜头移动。

## 数据与隔离

默认保存：`res://assets/world/tree_planting_test/edits.json`，再次保存保留上一版 `.bak`。
读取基准 `tree_layout.json`，只保存显式修改、新增记录和删除编号。原始树位与 F5 地图不变。
重启 F6 会重新载入保存结果；区外树木不显示，但其数据不会被删除。

导出后资源包不可写，测试保存路径自动改为 `user://tree_planting_test/edits.json`。
当前正式导出预设仍只包含正式游戏资源，尚未将种植工具加入发布版。
本次不加载草地、不重烘焙草，也未将人工测试树位接入正式游戏。
局部树采用近景模型，因此此场景用于测试布置功能，不代表全图 LOD 性能。

## 换地形、树种与颜色

场景根节点的 Profile Path 指向 `res://assets/world/tree_planting_test/current_map.tres`。
配置、整张地形和树种资源仅在运行时载入。入口及种植脚本不使用 `@tool`，
Godot 编辑器切换到该场景时不生成地形、树木或种植面板；按 F6 后使用游戏内编辑器。
复制场景与配置后可用于其他地形，运行时面板从配置生成，无需修改插件或引擎。

- 地形：替换 `terrain`，`terrain_metadata` 可留空；无元数据时，上向非水面可用于种树。
  `baseline_layout` 可留空，从空场地开始。更换地形或基准布局后使用另一个测试保存路径。
- 树种：在 `species` 数组加入 `TreePlantingSpecies`，设置唯一 id、显示名、模型、叶片贴图、
  叶片网格名称关键字和图集布局。默认适配本项目叶卡材质。
- 颜色：在 `palettes` 数组加入 `TreePlantingPalette`，设置深部、暗部、主色和亮部。
  默认有清脆绿、粉、金、橙、红与保留的原贴图绿。已保存的 id 应保持稳定。

测试布局带地形路径和基准哈希，变更后不匹配会拒绝载入，防止旧编号误套到新地图。
写入接口拒绝覆盖基准树位、地形元数据及其他非测试 JSON。

验证脚本：`tools/verify_tree_planting_test.gd` 检查数据隔离、多层贴地和新配置兼容；
`tools/verify_tree_planting_runtime.gd` 检查运行时面板、树冠射线、数值编辑、增删、撤销重做、
保存重载、切区和退出提示。日志和截图位于忽略目录 `.vegetation_art_build/tree_planting_test/`。
