# 游戏 UI 风格指南

2026 年 11 月 15 日确认项目采用**淡蓝手绘风**。初始神殿的战斗菜单、技能提示和对话框是当前实装参考。新界面按这套视觉规范设计。

- **配色。** 以偏白的纸色和低饱和淡蓝为主，正文用深蓝灰。可参考纸面 `#F7FBF7`、淡蓝 `#E5F1F5`、选中态 `#BAD6E5` 和正文 `#243F55`。选中或悬停时加深局部蓝色，保持文字可读。
- **笔触。** 在控件上使用细纸纹、轻微不规则的纸边、细铅笔线和少量线描图标。纹理和线描的强度以正文清晰为准。
- **场景。** 纸纹与色彩限制在控件范围内。战斗指令放在左侧，技能描述和对白放在底部，把画面中间留给角色与场景。用局部纸面提供文字对比度。
- **快感条。** 左右快感条复用旧版高对比样式，深色轨道上填充我方粉色渐变及对手橙红渐变。保留心形标识、百分比和描边文字。在天空、白墙和亮地面前检查填充边界与数值。

Godot 的 `gauge_palette` 可独立设置快感条颜色。初始神殿的淡蓝配色已引用原快感条配色，其他战斗界面可复用这一引用。[神殿淡蓝配色](../scenes/combat/temple_paper_palette.tres) · [原快感条配色](../scenes/combat/sparkle_ui_palette.tres) · [纸面着色器](../scenes/combat/encounter_paper.gdshader)
