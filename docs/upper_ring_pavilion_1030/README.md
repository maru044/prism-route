## 最新尺寸与场地

- 圆环中心 CAD 坐标 `(510, 115)`，朝向出生洞口；屋顶外径 145.6 米，中庭净开口直径 75.6 米。
- 主丘顶部标高 70 米，相对原地面抬升约 9.8 米；建筑地坪 70.08 米，屋顶底面 76.18 米。
- 另外两处丘顶分别抬升 5.2 米、4.2 米。主丘为宽阔丘顶与连续缓坡，坡脚在原路面和台地边缘前收回。
- 相对的前后入口贯穿圆环和中庭；后侧步道接现有上层道路，前侧入口接环建筑步道。
- 四条主要步道最大坡度约 17.7%、24.1%、19.4%、22.9%，约 10°–14°。步道为闭合薄板，连续衔接原地面；道路修剪边缘约 1.3 米宽的原有间隙由薄板门槛跨接。

## 建筑与材质

保留低矮圆环、局部屋面缺失和连续承重骨架。完整侧采用暖白复合板与低饱和蓝灰玻璃；破损侧露出耐候钢主梁、次梁、曲肋和连接板。两端均保留同等的入口空间，屋面破损保持非对称。

中庭已建种植池、浅水池、弧形坐凳和穿行空间。植物实例与表面绿化可在后续美术阶段填充。

材质为自行设置的简洁 PBR，没有下载写实锈蚀贴图。耐候钢基础色 `RGB(145,94,66)`、粗糙度 `0.84`、金属度 `0.18`，以温暖哑光棕锈色配合现有风格。
