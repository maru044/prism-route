# 基础地形与局部造型的组织方式

2026-10-16。用户指出现有基础地形不断被分块、补块，编辑成本持续增加。停止沿用“每次补缺口增加一个永久地形实体”的做法。

## 当前证据

此前对 10 月 16 日场景的清点发现，基础分区、跨槽连接、转角收口等地形被逐次拆分为多个实体。2026-10-18 已清理淘汰方案和重复副本，现用文件与图层见 [当前建模入口](CURRENT_MODEL.md)。本记录保留组织原则，历史检查快照已删除。

这里的问题是设计源被逐次补缝的边界支配。改变一个基础坡面后，周围连接块的高程和坡向都要重新调整。把这些实体简单 Join 或布尔成一个对象，只减少对象数量，并不能自动减少内部面和控制点，也不能恢复清晰的编辑关系。

## 目标组织

| 层级 | 职责 | 编辑方式 |
| --- | --- | --- |
| 基础地形 | 大尺度岸线、整体高差、连续坡度、地面覆盖 | 每个连续陆地区域一个主要基底对象，以少量主曲线及主曲面控制；不按局部接缝继续拆块 |
| 局部造型 | 微丘、独立山体、建筑化隆起等有明确造型意义的体量 | 独立可调整实体；与基底相融时保留操作源，重新生成结果 |
| 切除体 | 已设计的洞口、局部开槽等 | 独立切除体及参数，保留布尔前基底；不得借本次整理新增或加长隧道 |
| 桥与建筑 | 桥面、支撑、独立建筑 | 独立于基础地形；用户明确指出的未来桥梁位置继续保持断开 |
| 材质和植被 | 地表覆盖和散布 | 后续设计的遮罩或分布数据；不为了贴图分区切开基础几何 |

“一个主要基底对象”不要求整个区域必须是一张巨大 NURBS 曲面。允许少量有清晰控制关系的曲面组成连续体；不以单面或单对象的数量指标替代实际可编辑性。分岛、水域和桥梁之间真正分开的区域不强行连成一体。

## 下一次几何修改的入口

1. 保存目前版本为形态参考，保留用户的 `1016参考曲线`、两条有高程的顶面控制曲线及落地轮廓。
2. 先确定当前陆地区域的统一基底覆盖范围、岸线和主要高差，包含原来需要 `06`～`09` 补块才能覆盖的基础地面区域。禁止占用水域或未来桥梁预留。
3. 从主控制曲线重建连续基底，而不是把现有分块边逐条作为新曲面的约束。旧补块可作为局部形态采样参考，不再作为长期编辑源。
4. 基底确认后再处理有意义的局部丘陵、支撑和已有切除。保留基底与操作体，布尔结果为派生对象；游戏输出也从同一设计源生成。
5. 使用整体视角检验体量和坡度，再检验局部连接。以调整一条主曲线后能否稳定更新整个基底作为维护性检查。

本记录初次编写时只清点和记录结构调整方向，没有合并、删除或重建 Rhino 中的任何实体。

## 材质分区与种植边界（2026-10-18）

以下是早期几何投影试验记录。当前游戏实现已采用 CAD 控制的世界空间材质遮罩，原网格内直接混合草地与暖白表面；不再发布抬高的覆盖网格。当前步骤和已验证的限制以 [当前建模入口](CURRENT_MODEL.md) 的世界遮罩章节为准。

1. 以连贯的景观区域为单位画少量可编辑闭合主曲线。范围根据坡面流向、丘陵和通行空间确定，允许跨越几个地形组件；不沿每个组件边缘统一内缩。白色建筑面用于保留翻卷边缘、拱肩、洞唇和有意义的步行空间，宽度随造型变化。
2. 为每个区域明确接收对象和顶面。普通缓坡可以从平面曲线沿 Z 向投影；陡面、重叠丘陵和悬挑需要单独选面、必要时改投影方向。不得把桥底、隧道内壁、被遮挡的底层或道路误作草地接收面。投影闭合不等于景观设计正确，必须在真实视图检查。
3. 在接收面的内存副本上 Split，保留位于设计边界内的区域。除重心外，还需检查裁片边缘采样点，避免误选重心恰好也在范围内的巨大补集。保持原基础地形不变，覆盖面是可删、可重新生成的派生结果。
4. 边界确认后再发布草地表皮，记录设计源、宿主编号及面索引；上覆草层采用受控的微小间隔避免闪烁，并检查接缝、道路净距和是否被其他组件遮住。不为材质区域累积基础实体和永久布尔碎块。
5. 暖白建筑面与草地采用独立材质。生成游戏资产时可将派生范围转成材质分区或遮罩，是否烘焙应在游戏导入验证时决定；当前 Rhino 投影试验尚不代表引擎中的最终显示已验证。

现用边界样例与清理结果见 [当前建模入口](CURRENT_MODEL.md)。用户可调整现有平面源，或手动画闭合范围并标注希望种草的一侧，无需重画整片地形控制线。
