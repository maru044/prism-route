# 岛顶倾覆曲面遗址

本阶段在 Rhino 中建模。主体定位依据 `marked_placement.json`：使用用户标注截图对应的实际 Rhino 视口，将红圈投影到 Z=63 m 屋顶，再在该区域内组织两片上翘翼与凹入的后缘。红圈用于定位，最终外轮廓保留翼角，不做成圆形顶盖。原有椭圆体与内部未编辑。

图层：`建筑::岛顶倾覆曲面遗址`。`00_控制母面` 默认隐藏并锁定，包含原生双三次 NURBS 高度母面、平面边界与边缘控制曲线。钢网架、上下弦杆、节点腹杆、残存菱形表皮、下垂角部面板和短支座分层组织。所有对象带有 `feature=island_saddle_1030` 标签。

主体已按用户反馈缩小：平面按原版的 52% 重建，主体范围约 190 × 119 m，面积约为原主体的 27%，高度保留约 24.6 m。中央网壳同时抬起，增加下方空间。靠高架的接触区保持原位，主体与接触区之间通过连续的平面映射过渡，避免把整座构件等比缩放后拉离桥缘。

母面、钢架与表皮共用同一个连续曲面。按圈选反馈，衔接叶瓣已局部抬升：低位钢弦控制高程改为约 64.65 m，进入岛顶前平滑拱起，落地处局部回落。避免旧控制高程 62.76 m 将大段钢架埋在 Z=63 m 的屋顶内部。距落地点 15 m 以外的衔接表皮，采样到的屋顶净高至少约 1.50 m。

悬空角部由窄条面板改成一张连续、不透明、封闭的薄壳，补齐整个悬空区域；进入屋顶后才逐渐收窄，与残存破损表皮衔接。菱形接缝是装饰网格，后续不参与游戏碰撞。高架接触端约 2.4 m 宽，贴合真正可通行的路面边缘，高差约 -1～23 mm，平面间距约 1～14 mm。屋顶落地处薄壳稍向内延伸，接续高差约 33～55 mm。实际通路最大纵坡约 15.5%，约 8.8°。较低的壳体角部通过短钢支座落在屋顶。

v3 约 11.8 万三角形、175 个对象。v4 将渲染表皮分离为实心与玻璃两部分，同时原样保留隐藏碰撞薄壳，共 177 个对象，其中 172 个可见、4 个隐藏控制对象和 1 个隐藏碰撞对象。钢网格采用两组斜向曲线，主体间距约 10.4 m，原控制坐标间距 20 m；上弦半径 0.19 m、部分下弦 0.13 m，弦杆间距 0.72 m。所有杆件从母面生成，保持圆形截面。残存表皮按同一菱形网格布置，并留出不对称破损区域。材质为象牙灰金属、低饱和耐候金属、浅色板材与淡蓝灰玻璃。

原有对象的几何 CRC 在建模前后逐项核对。`model_report.json` 记录新对象编号、三角形数、最高点、椭圆体平面净空与高架接触采样。`walking_surface_samples.json` 保留通行表皮的采样点。后续已导入正式 Godot 地图并通过双向行走测试，现有树木种植全部保留，详见 [实机导入记录](game/README.md)。
