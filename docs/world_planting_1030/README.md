# 正式大世界 · 植物编辑与游玩

2026-10-30。F5 仍运行 `scenes/map_1021.tscn`，地图面板增加「植物编辑 · F4」。F4 在编辑与游玩之间切换；原 `scenes/tree_planting_test.tscn` 也已指向同一个正式世界，直接从环庭进入编辑。

## 使用

1. 在游玩模式走到目标区域，按 F4 或点击「植物编辑」。环庭可从出生点菜单选择「上层环庭 · 中庭入口」。
2. 原有随机树位与中庭人工种植均作为底稿。左键选择，直接拖动树冠也能移动；移动工具支持 X/Y/Z 坐标轴约束。移动后保留工具和选中对象，可继续拖动、点地面，或直接选择另一棵树。
3. Q/W/E/R 为选择/移动/旋转/缩放，I 为新增。旋转可拖动树或旋转环，缩放可拖动树或方形手柄。Shift 精调，Ctrl 吸附（移动 0.5 米、旋转 15°、缩放 0.1）。Esc 或右键取消正在进行的变换；没有正在进行的变换时，Esc 先退回选择，再取消选择。
4. Alt+拖动复制并移动，Ctrl+D 复制，Delete 删除，F 或双击定位。换树种/颜色直接生效；新增工具中改树种、颜色、大小或朝向，只影响后续种植，不改之前选中的树。连续新增保留预设，并显示可放置的绿色圆环；无效位置为红色。
5. 一次拖动、Alt+拖动复制、连续调数值各合并为一步撤销，Ctrl+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做。撤销只增删或更新实际改变的树，不重建整片区域。数值框输入时不会触发场景工具快捷键；保存会先应用尚未按 Enter 的数值。
6. 右键转向，按住右键 + WASD/QE 飞行（QE 沿世界竖直方向），Shift 加速、Ctrl 慢速，右键 + 滚轮调飞行速度。中键平移，Alt+中键绕选中树旋转；普通滚轮朝光标方向按距离缩放。松键、切换模式和窗口失焦时停止镜头操作。
7. 飞到另一处后点击「载入镜头中心附近」会原地载入，不跳镜头；区域菜单选中即定位。每次只将当前楼层附近最多 120 棵树转成操作对象；其他树始终保留批量渲染。撤销历史属于当前载入区域，换区后清空，已经做出的修改保留。
8. F4 回游玩时保留本次未保存的调整、当前工具、选中树、撤销历史和编辑镜头。角色保留原位置，也可以点击「在镜头指向处游玩」，通过地面/空间检查后从该处体验。
9. 点击「保存并应用」或 Ctrl+S 后，下次 F5 自动载入。退出时若有未保存调整，会提供保存、继续编辑或放弃退出的选择。

当前阶段编辑树木，草地密度与清除笔刷尚未加入。

## 白桦与湖畔布置

树种菜单新增「白桦树」，可以新增，也可以将选中树改为白桦。使用已有的白桦树冠、独立叶片图集、连通树干和白色树皮；编辑对象与保存后重新批量渲染使用同一套资源。默认绿色采用白桦自己的浅灰绿色板，避免被通用鲜绿色覆盖，其他显式颜色仍可选择。

已在湖畔缓坡布置 3 簇、共 15 棵，大小约 0.92～1.22 倍，根部通过正式碰撞面贴地，避开道路、陡面和已有树根。F5 后按 F4，在区域菜单选择「湖畔 · 白桦缓坡」即可检查和继续修改。

近景保留原树冠，中景使用 12 个双面叶团卡片，远景使用 8 向图集；每棵树的叶片三角形为 4608 / 48 / 4。新生成的是白桦专用 LOD，原始模型与其他树种资产不变。使用统一的批量渲染、风动、叶片光照和水面反射流程。

验证与实机截图见 [白桦报告](birch/report.json)、[重新加载的湖畔](birch/reloaded.png)。`tools/verify_birch_planting_1030.gd` 先复制正式人工布局到隔离草稿，验证新增、白色树皮、专用灰绿色板、复制/换树种撤销、保存重载与真实批量实例；`--apply` 仅在验证通过、正式文件哈希未变化时写回，并保留 `.bak`。原有手工树位、删除记录、草地缓存与两个湖畔遮罩均受保护。

## 数据与渲染

- 共享正式地形、建筑、光照、树干、叶片、配色与三个 LOD；编辑对象也调用正式植被的 `_add_tree_lod_level()`，不会使用另一套预览材质。附近树木的原批量实例暂时隐藏，避免重影。
- `world_editor.gd` 先读取现有随机布局，精确沿用原有树种随机数、区域配色、避让和土丘贴地，再合并人工修改。中庭树使用 `ring_*` 稳定编号，原随机树使用基准行编号；用户新增树分配独立编号。
- 正式保存文件：`assets/world/tree_planting/world_edits.json`，只记录改动、新增与删除。原始 `tree_layout.json`、模型和草地缓存保持不变。保存写临时文件后替换，保留上一版 `.bak`。
- 导出版本无法写入资源包，使用 `user://world_planting/world_edits.json`；首次无用户布局时可读取资源包内随项目发布的布局。导出过滤包含正式保存文件。
- 如果基准树位哈希不匹配或保存数据无效，保留原文件，显示提示并禁止覆盖；不会默默丢弃旧布局再保存。
- 人工调整覆盖随机避让结果，不会因为靠近建筑再次被随机规则删除。森林环境音索引在应用后更新；海面反射移除失效对象，并同步移动中的树；中庭静态反射探针在应用后短暂重新捕捉。
- 草地代码通过原 `map_1021_vegetation.gd` 继承。新增 `world_vegetation.gd` 只替换树位批量构建，草地签名保持 `ba956502a5277980535f7cf593721cb5134809971f52bead4c27ffa765ecd70a`。
