# 小植物场景的大风测试（2026-10-25）

入口：`res://scenes/vegetation_grove_test.tscn`，在 Godot 中打开并按 **F6**。
右上角「草地风力测试」可选择微风、大风或自动切换。默认自动：每 24 秒一个循环，
前 8 秒微风，然后增强；第 19 秒开始减弱。增强、减弱各约 3 秒，期间保持风场连续。
相机操作仍为 WASD、Q/E、Shift、鼠标右键和滚轮，没有增加快捷键。

## 模型与动画

- 新模型 `assets/vegetation/models/grass_star_3card_gust_v7.glb`：三张交叉草片，正反面均有几何，
  60 顶点、48 三角形；高度方向四段、五层顶点。尺寸、UV、贴图和草丛位置保持。
- 源文件 `assets/vegetation/source/grass_star_3card_gust_v7.blend`；生成脚本
  `tools/build_grass_gust_model.py`。原 v6 模型没有覆盖。
- 顶点色 R 保存连续高度权重。草根固定，中心线沿保持解析弧长的圆弧弯曲；
  宽草片保持横向宽度框架，避免把整张草丛当窄叶旋转后边角翘起。
  四段折线是对圆弧的离散近似，不是精确的柔性植物物理。
- 大风主运动改为持续受迫往复：每秒约 2.1 次明显的「弯—回弹—弯」。
  上一版 6.8 秒一次、保持 2.4 秒的阶跃脉冲会长时间停在倾斜状态，已从测试变体中移除。
  仍不保存逐株物理状态，统一按全场时间求值；随机 yaw 不改变世界风向。
- `gust_sway_hz=2.1` 明确以 Hz 为单位，`gust_base_angle=0.60 rad` 保留顺风倾斜，
  `gust_sway_amplitude=0.51 rad` 控制大幅往复。二次谐波令弯折与回弹时间不完全对称；
  次要振动、缓慢的幅度/相位调制提供变化，慢包络不再控制单次弯折。
  这些是当前美术测试参数，不是所有草种的实测固有频率，也不是完整的植物动力学求解。
- 按最新反馈，大风采用**全场同步弯折、同步回弹**。去掉上一版的麦浪传播、空间噪声相位、
  逐株相位/幅度差，以及方位的空间差异；次要振动与慢包络也统一使用全场时间。
  完全进入大风后，原微风位移不再叠加到大风角度中，避免再次出现局部先后变化。
  微风模式保持原来的局部噪声摆动，过渡期间逐渐淡出/淡入；根到梢的弧线方法保持。
- 法线随弯曲调整，保留柔和的向上偏置。草颜色、透明裁剪、微风噪声和分区代码共用。
- `grass_gust.gdshader` 显式定义 `GRASS_GUST_DEMO`；正常 `vegetation_wind.gdshader`
  不定义它。两者引用 `vegetation_wind_common.gdshaderinc`，大风代码仅编译进测试变体。
  原补光版本生成工具已适配共享代码的位置。

只在 `grove_demo` 小场景中启用新网格、测试着色器和切换面板。F5 的 1021 地图继续用原模型、
原微风入口；草分布/缓存生成输入没有改变，不要求重烘焙。树叶风动也未切换为草的大风。

## 几何与开销

新模型关闭导入时的自动网格 LOD：静止的直草片会被简化掉中间顶点，导致运行时弧线失效。
小测试场景暂时所有草丛均用四段网格，并扩展 1.8 m 剔除边界；密度仍为 63,000 丛。
正式推广前可以另做保留曲线形态的近/中/远网格。

固定镜头 1600×900、Godot 4.7.2 Forward+ / D3D12 / RTX 5070 Ti，暖机后 90 帧 GPU 时间中位数：

| 模式 | GPU 时间 |
| --- | ---: |
| 原 v6 模型及微风 | 4.61 ms |
| 四段模型、微风 | 6.54 ms |
| 四段模型、大风 | 6.91 ms |

这是整个小场景的特定机位测试，包含树、角色和界面。主要差异来自几何细分与禁用会破坏曲线的
自动简化；不能据微风/大风的微小差值声称大风计算没有开销，也不代表大地图性能。

## 验证与重现

`tools/verify_grass_gust.gd` 使用真实 GPU 检查：

- 原草与新草在微风、相同细节级别下的图像对比；差异阈值 3/255，仅 16 像素超过阈值。
- 固定角度下的草梢下降、根线稳定、世界风向不随实例 yaw 改变。
- 分别在 0–3 秒和 18–21 秒按 24 Hz 采样真实 GPU 轮廓，检测到 6 / 7 次大幅往复，
  水平方向跨度 46 / 45 像素，草梢高度跨度 37 / 36 像素；根线保持稳定。
  同时检查相邻 0.1 ms 的图像变化，排除突然跳变。
- 在 5 个冻结时刻，分别把相同草丛移动到 3 个不同世界位置并同步平移相机。
  15 次 GPU 图像对比最多只有 1 像素超过 3/255 差异，确认强风形变不随空间位置延迟。
- 小场景数量、额外剔除范围、三种模式选择、平滑过渡、自动回到微风。
- 同机位原模型/细分微风/细分大风的 GPU 计时。
