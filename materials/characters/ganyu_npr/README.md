# Ganyu C1 numerical maps

Generated by `tools/export_character_npr_inputs.gd` followed by
`tools/build_character_npr_maps.py`. See `docs/CHARACTER_NPR_C1.md`.

`face_sdf.png`: R/G are signed-distance-derived switching fields for right/left
head-relative light; B is the rasterized face UV coverage; A is 1. Authored from
an explicit front-projection cheek/nose boundary, rasterized through this mesh's
UV. Not an official game SDF, and not reconstructed from the face BaseColor.

`body_material_mask.png`: R is the atlas-specific gold-color candidate selection,
G the white-cloth selection, B reserved. The selection recipe is deliberately
restricted to this atlas and needs artistic review when an atlas/model changes.

Both maps are linear numeric data, losslessly stored, sampled without
`source_color`. Keep automatic 3D compression disabled. Geometry and atlas hashes
and channel definitions are recorded in `build_report.json`.
