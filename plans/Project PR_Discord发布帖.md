# 标题

【纯文字／初音未来／海岛·房车·生活】和 Miku 一起逛逛海岛吧！Project PR 导览卡

# 首楼正文

**岛还在建设，导览员已经开始上班了。**

大家好，我是古菌工作室的 archaea。最近在为社区制作一款以海岛、房车和日常生活为主题的 3D 游戏 **Project PR / Prism Route**，今天先带来同世界观的 **Miku 纯文字导览卡**，以及一段目前版本的实机预览。

**🌿 海风、白色巨构，还有一辆停在泻湖边的房车**

这里是一座被自然慢慢接管的科技海岛。南面是洞穴、断崖与流线型的白色建筑，北面是草甸、沙滩和清澈的泻湖。公路穿过半露天隧道与高桥，最后延伸到海边。

而 Miku 已经在房车旁支起天幕、准备好茶，等你过来坐坐了。

她是负责接待旅人的 AI 助手，也是能随时打破第四面墙的系统管理员。元气、爱吐槽，有一点小傲娇；你可以让她带路，也可以直接问她：“开发者到底做到哪一步了？”

**💬 这张卡可以聊什么？**

• **文字伴游**：点一个感兴趣的地方，让 Miku 带你逛洞穴、主桥、屋顶花园或双泻湖，听她介绍沿途的风景。
• **房车与营地日常**：在天幕下喝茶、聊旅行，或者和她一起设想理想中的湖畔营地。
• **游戏问答**：了解海岛的世界观、美术方向，以及当前完成的场景和后续系统企划。
• **一起讨论点子**：想在哪里扎营、希望遇见怎样的角色、期待怎样的同居日常，都可以和她聊。

卡内含男性向、百合与成人向世界观设定，整体偏轻松日常。导览和闲聊也可以单独进行。

**🎬 游戏目前的样子**

随帖附上约 **41 秒实机预览**，展示角色出洞、草地探索、房车行驶和浅水场景。

目前已跑通海岛场景、角色步行与房车驾驶，并持续调整植被、角色和水面的表现。后续想继续做全息角色探索与重塑、营地建造，以及角色共同生活等内容；这些属于开发规划，具体实现会逐步更新。

**本次可直接体验的是酒馆中的文字导览卡。3D 游戏仍在开发，文字伴游中的描写也包含世界观设想。**

**📥 下载与使用**

下载本帖附带的 **「Project PR游戏介绍.json」**，作为角色卡导入酒馆。文件内已包含世界书，文字导览不需要额外前端或脚本。

导入后可以直接发一句：

> Miku，先带我去泻湖边坐坐吧，路上介绍一下这座岛。

或者：

> 现在已经完成了哪些内容？哪些还在规划中？

**🛠️ 关于这一版**

目前是初版导览卡，内容会随开发进度调整。Miku 的回答由聊天模型生成；具体进度以作者更新和实机演示为准。

欢迎反馈导览中不清楚的地方，也欢迎聊聊你希望在这座岛上体验怎样的生活。希望以后能把这些风景与日常，一点点做进游戏里。
