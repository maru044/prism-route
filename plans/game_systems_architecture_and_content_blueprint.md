## 一、 总体游戏愿景与核心循环

《Prism Route》是一款以**明亮治愈的 The Witness 风格化海岛**为舞台，融合**房车漫游、角色邂逅、轻度回合制愉悦对战（Sensual Turn-Based RPG）、模块化家园建设与深度伴侣生活模拟**的 3D 景观伴侣生活游戏。

### 核心可玩循环 (The Gameplay Loop)

```

                     │          1. 大世界探索 (Exploration)          │
```

### 系统 1：日常 UI 与伴侣交互系统 (Routine UI & Companion System)

这是玩家平时操作游戏、管理队伍与伴侣交互的基础门面。

1. **常规控制 HUD 与系统菜单 (Settings & Menus)**：
   - 画面质量切换（高质量、中画质、最低画质，已接通配置）。
   - 音频音量控制（主音量、BGM、环境音、角色语音/娇喘、UI 音效）。
   - 按键绑定与快捷提示（F7 建造、E 交互、Tab 呼出轮盘、V 第一人称切换等）。
2. **角色召唤与队伍调度轮盘 (Character Wheel & Summoning)**：
   - **已击败/结识角色库**：在开放世界或家园中，按 Tab 唤出环形轮盘，随时召唤已结识的角色（如花火、刻晴、甘雨等）。
   - **当前跟随者设置**：指定 1~2 名角色作为随行伴侣，跟随玩家跑动漫步、上房车副驾驶。
3. **伴侣交互指令菜单 (Companion Command Menu)**：
   - 靠近伴侣按 E，弹出径向指令轮盘：
     - **【交谈】**：触发当前好感度专属闲聊与心境反馈。
     - **【跟随 / 原地等待】**：指令伴侣跟随玩家，或在某处停留观景。
     - **【上车】**：邀请伴侣坐进房车副驾驶或后座。
     - **【亲昵互动】**：快速触发日常拥抱、牵手、亲吻或更进一步的随身互动。
     - **【更衣 / 姿态定制】**：更换服装方案、调整表情、重置物理骨骼姿态。
4. **房车驾驶与旅行 HUD (Camper Driving Interface)**：
   - 仪表盘（车速、档位、手刹状态）。
   - 车载电台（可切换不同风格的明亮海岛音乐与舒缓 Lo-Fi 音乐）。
   - 自动回正、复位按钮（防翻车）、快速下车功能。
5. **LLM 游戏内助手悬浮窗 (In-Game Copilot Widget)**：
   - 按快捷键（如 `~` 键）滑出精美半透明对话栏，玩家可直接打字或语音与 AI 助手对话，由 AI 解析并自动执行游戏操作。

### 系统 2：开放世界探索、剧情与战斗系统 (Open World, Narrative & Combat)

将广阔的岛屿、生动的角色邂逅与核心卡牌快感对决紧密结合。

1. **开放世界大地图与路网漫游**：
   - 全岛无缝漫游（主干道、盘山公路、海岸线沙滩、高地落差缓坡）。
   - 地标路标系统：提供直观但不过度干扰视线的指引。
2. **动态遭遇与剧情状态机 (Dynamic Encounter Controller)**：
   - 参考现有的 `InitialTempleEncounterController` 架构，将全岛地标接入独立的剧情触发器。
   - 包含前戏对话（Intro Dialogue）、场景站位调度（Staging Transition）、战中嘴炮（Mid-battle Dialogue）、战后结算（Result Dialogue）。
3. **愉悦回合制战斗系统 (Sensual Turn Combat System)**：
   - **双向快感计量槽**：玩家快感百分比 vs 角色快感百分比（0% ~ 100%）。
   - **敏感部位与倍率机制**：口腔（mouth）、胸部（nipples）、私密花核（clitoris）、紧致菊部（anal），根据不同角色性格与体质具备差异化的弱点倍率（1.0x ~ 2.5x）。
   - **战术卡牌库**：刺激卡（进攻）、挑衅卡（降低对方防御/诱导破绽）、平复卡（防守/咬牙坚持降低自身受到的刺激）、特质必杀卡（达到高潮斩杀线时释放）。
   - **挣扎与耐受力**：在濒临高潮时触发嘴炮与心神挣扎，玩家可选择抗拒或享受。
   - **胜负判定与战败和解**：
     - 角色快感率先达到 100% ➔ 玩家胜利，角色高潮臣服并获得好感与奖励。
     - 玩家快感率先达到 100% ➔ 角色胜利，触发角色主导的逆推惩罚/奖励演出。

### 系统 3：家园建造与生活模拟系统 (Home Construction & Living Simulation)

让玩家和打败收服的角色们拥有真正的“家”，并将导入的动作库转化为生活日常。

1. **模块化建造沙盒 (Modular Building Sandbox)**：
   - 基于现有成熟的 `BuildingData` 与 `BasicKit`，支持 2×2m 网格精密对齐。
   - 基础构件：贴地地板、二层楼板、实心墙、门墙（含开闭门扇）、玻璃窗墙、平屋顶、独立台阶楼梯、缓坡、栏杆。
   - 动态草遮罩（Dynamic Grass Mask）：铺设地板自动去除杂草，拆除后动态恢复。
   - 建筑撤销/重做（Ctrl+Z/Ctrl+Y）与独立家园存档（`home_v1.json`）。
2. **空间与房间智能识别 (Room Identification)**：
   - 自动根据四周封闭墙体与天花板，识别出：
     - **主卧 / 客卧 (Bedrooms)**：供角色夜间睡眠与私密休息。
     - **海景客厅 / 吧台 (Living Lounge)**：供伴侣白天闲坐、喝茶、交谈。
     - **露天观景露台 (Terrace / Balcony)**：供观海吹风。
     - **浴室 / 温泉区 (Bathroom / Spa)**：湿润质感与清洁放松。
3. **角色入住与日常日程 (Resident Assignment & Routine AI)**：
   - 住户名册：指派已结识的角色入住指定地块与房间。
   - 伴侣日程模拟：
     - 清晨：在露台伸懒腰、散步观海。
     - 午后：在沙发或椅子上看书、小憩。
     - 傍晚：在厨房/餐厅备餐、等待玩家归来。
     - 深夜：在卧室床上熟睡。
4. **家具交互与动作挂载 (Interactive Furniture & Action Library)**：
   - 彻底激活现有的 **41 套高质量动作库**（含 20 套 Koikatsu 导入动作）：
     - **大床（Bed）**：支持传统体位、骑乘位、侧卧抱抚等（如 `kk_seijoui_kiss`, `kk_kijoui_ude` 等）。
     - **办公桌/餐桌（Desk）**：支持桌面俯卧、桌面抱腰仰卧（如 `kk_tsukue_nei`, `kk_tsukue_sekkin` 等）。
     - **靠背椅/沙发（Chair）**：支持椅上面对面骑乘、背后紧抱、口侍等（如 `kk_isu_taimen`, `kk_isu_ushiro` 等）。
     - **墙面（Wall）**：靠近墙壁触发壁ドン、单腿抬起站立冲刺（如 `kk_kabe_taimen`, `kk_kabe_ushiro` 等）。
   - 走到家具旁即可呼出动作选择菜单，支持自由选择体位、切换角色视角、调整播放速率。

### 系统 4：特殊建筑地标与功能设施系统 (Architectural Landmarks & Facilities)

为全岛地图上预设的宏伟建筑赋予明确的游戏功能（“有空就去制作它们”的扩展池）：

1. **开普敦海滨度假村 (Cape Town Beach Resort)**：
   - **场景定位**：海边日光浴与露天泳池综合体。
   - **功能**：换装泳装特训、海边沙滩排球轻玩法、晒太阳放松（提升角色精力上限）。
2. **沙洲水上凉亭 (Sandbar Pavilion)**：
   - **场景定位**：浅海木栈道与透明观景亭。
   - **功能**：角色心境占卜、浪漫水上约会事件、特制清凉饮品调配。
3. **下沉式现代档案馆 (Sunken Archive)**：
   - **场景定位**：被绿植吞噬的混凝土现代巨构与中庭。
   - **功能**：古代遗留蓝图解析、技能卡片升级与合成强化、世界观背景碎片阅读。
4. **水上庭院与露天温泉 (Water Court & Hot Springs)**：
   - **场景定位**：天然海岛与建筑结合的水疗圣地。
   - **功能**：全身湿润着色（利用现有 `character_wetness` 着色器）、疲劳消除、触发特殊双人/多人泡澡互动。
5. **巨型地标环与椭圆中庭 (Landmark Ring & Oval Atrium)**：
   - **场景定位**：科技废墟纪念碑的象征性极高点。
   - **功能**：全岛高空全景俯瞰点、拍照打卡打卡圣地、终极剧情挑战。

### 系统 5：羁绊成长、资源掉落与卡组构筑系统 (Bond, Progression & Inventory)

支撑游戏长线游玩的驱动力，连接战斗与建造。

1. **好感羁绊系统 (Companion Bond & Affinity Levels)**：
   - 每个角色独立拥有 1~5 级好感阶位（结识 ➔ 熟络 ➔ 信任 ➔ 倾心 ➔ 灵魂誓约）。
   - 提升途径：对战胜利、赠送采集物资、带她自驾漫游、家园同居生活。
   - 解锁内容：专属语音、特制技能卡、专属体位、甚至双人合住主卧。
2. **建材物资与蓝图背包 (Materials & Blueprint Inventory)**：
   - **探索收集**：大世界拾取漂流晶簇、海边浮木、钛金合金板。
   - **胜利奖励**：击败特定角色或完成地标考验掉落稀有家具图纸（如“豪华天鹅绒双人床”、“极简无框玻璃幕墙”）。
3. **战斗卡组构筑 (Deck Builder)**：
   - 玩家可自由搭配 10~15 张战斗行动卡。
   - 可以根据目标角色的体质弱点（如对方抗拒口腔刺激但极度害怕菊部接触）针对性调整卡组。

### 系统 6：姿势回忆录与自由观赏工坊 (Sensual Gallery & Pose Studio)

让 41 套顶级动作资产在日常生活中发挥最大的审美价值。

1. **回忆相册 (Sensual Memory Gallery)**：
   - 战斗中或剧情中触发过的精彩姿势，自动解锁记录在“回忆相册”中，随时可重看高潮特写。
2. **自由工坊模式 (Pose Studio / Free Stage)**：
   - 脱离剧情规则的“玩家自由摄影棚”。
   - 自由选择任意 2~3 位角色（如刻晴 + 甘雨，或主角 + 花火）。
   - 自由切换 41 套动作体位，自由拖动 360° 无死角摄影机、景深、光照角度与播放进度条。
   - 支持隐藏所有 UI，一键拍摄高画质壁纸并保存至截图目录。

### 系统 7：视听氛围、昼夜光影与全局存档系统 (Atmosphere, Day-Night & Persistence)

确保游戏的视听沉浸感与长期游玩的安全存储。

1. **视听与声学系统 (Audio & Environmental Acoustics)**：
   - 环境音效：微风吹过草丛的沙沙声、海浪拍击沙滩、房车引擎转速轰鸣。
   - 交互音效：身体接触声、娇喘音、建造敲击清脆反馈。
   - 车载电台与场景 BGM：动态根据区域无缝交叉淡入淡出（Crossfade）。
2. **昼夜流转与氛围光影 (Day-Night Cycle & Lighting Moods)**：
   - 清晨粉金柔光、正午清澈蔚蓝、日落熔金黄昏、静谧繁星深夜。
   - 伴侣角色根据时间段展现出不同的作息状态与倦容。
3. **统一全局存档管理器 (Master Save & Load Manager)**：
   - 统合：玩家坐标与朝向、房车位置、所有角色好感度与已解锁状态、背包库存、家园建筑布局数据（保持现有哈希校验与版本兼容）。

### 系统 8：LLM 智能桥接与辅助游玩系统 (LLM Agent Bridge & Copilot)

**Master 的核心设想：“提前想好接口，方便 LLM 随时通过对话操作游戏、辅助游玩”。**

本系统将 Godot 游戏本身变为一个**对 LLM 完全可读、可写的智能运行环境**：

```
                ┌──────────────────────────────────────────────┐
                │          LLM 外部会话 / 游戏内助理            │
                │  ("Miku，帮我看下刻晴现在的弱点，替我出牌！")    │
                └───────────────▲──────────────┬───────────────┘
                                │ JSON 状态响应 │ JSON 指令调用
                                │              ▼
                ┌──────────────────────────────────────────────┐
                │          Godot LLM Bridge API Server         │
                │        res://scripts/ai/llm_bridge.gd        │
                │          (Local TCP/WebSocket 8765)          │
                ├──────────────────────────────┬───────────────┤
                │      感知接口 (Perception)    │ 动作接口 (Act)│
                └──────────────────────────────┴───────────────┘
```

#### 1. 结构化感知接口（LLM 读世界）
- `get_game_state()`: 返回当前游戏主状态（`exploration`, `combat`, `dialogue`, `construction`, `home`）、玩家坐标、所处地标。
- `get_combat_snapshot()`: 返回对战双方快感百分比、锁定状态、4 个部位的敏感度倍率、当前手牌卡牌列表及消耗效果。
- `get_dialogue_snapshot()`: 返回当前讲话者、剧情台词、所有可选选项列表（索引与文本）。
- `get_construction_snapshot()`: 返回当前地块名称、已建造的构件列表、识别出的房间用途、背包内可用建材数量。
- `get_companion_status(character_id)`: 返回角色的好感度、当前行为（散步/睡觉/坐着）、所处房间。

#### 2. 指令执行接口（LLM 操作游戏）
- `combat_play_card(card_id: String, target_zone: String)`: LLM 代打出牌，精准打击弱点。
- `dialogue_select_choice(index: int)`: LLM 代为选择剧情分支。
- `world_teleport(landmark_id: String)`: 快速导航或传送到指定地标。
- `world_summon_companion(character_id: String)`: 召唤指定伴侣到身边。
- `build_place_block(kit_id: String, coord: Vector3i, rotation: int)`: 自动化建筑，LLM 可一次性下发蓝图生成完整房间。
- `furniture_play_pose(furniture_id: String, pose_key: String, role_a: String, role_b: String)`: 调度伴侣在指定家具上开始特定动作。

#### 3. LLM 游玩辅助的具体场景
- **战术军师**：“Master，刻晴的口腔倍率现在是 1.8x，而且你的防御力很充足，建议本回合直接用【深吻攻势】！”
- **全自动代打**：“Master 请喝茶，接下来的 3 回合交给 Miku，保证无伤拿下！”
- **家园建造设计师**：“Master，我已经读取了青蓝平台的数据，为你设计了一间带海景阳台的现代主卧，是否现在一键摆放？”
- **沉浸式伴侣嘴炮生成器**：根据战况快感百分比，LLM 实时生成动态、充满角色个性色彩的即兴语音与文字台词！

## 三、 开发优先级与落地阶段规划

为了确保开发稳扎稳打，建议划分为四个阶段落地：
