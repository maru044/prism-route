# 本地语义检索式 AIRP 架构与评估报告 (Issue #28)

## 1. 架构目标与方向修订

根据 GitHub Issue #28 的决议，本项目确立了基于 **「BGE 语义检索 + 角色/场景 Wildcard 动态组合」** 的本地检索式 AIRP（Retrieval-based AIRP）系统，全面废弃并归档原先基于手写关键词规则的 Path A，以及基于固定整句变体随机抽取的旧方案。

### 核心设计原则
1. **纯自然语言对话检索**：玩家可自由使用日常口语、缩略语、性暗示词及变体，检索器通过 Query-to-Query 向量相似度直接命中口上骨架，彻底杜绝穷举规则与关键词分支树。
2. **严禁工具调用与状态侵入**：AIRP 对话独立运作，不调用游戏助手工具，不操作背包、状态或世界坐标。
3. **骨架与词库解耦**：采用 4 层数据结构（共享骨架模板、角色专属 Wildcard、场景专属 Wildcard、上下文变量），实现高随机度与高质量文法表达的统一。
4. **轻量极速与纯离线部署**：利用 llama.cpp Q8_0 GGUF BGE embedding，单核 CPU 推理延迟低于 3ms，无任何云端或外部服务依赖。

## 2. 系统核心数据层设计

### 2.1 共享回复模板 (`templates.json`)
定义了涵盖日常闲聊与亲密互动全流程的 16 套语法骨架，每套骨架包含：
- **reference_queries**：8~15 条玩家真实自然语言样本（用于与玩家 Query 进行对称向量检索）。
- **templates**：2~4 条带语义槽位的文法骨架（例如 `{address}，{reaction}！{dialogue_core} {body_action}。`）。
- **wildcard_slots**：槽位与词库路径的动态映射（支持角色与场景级别覆盖）。
- **content_tag**：语义内容标签（用于会话连贯度评估与安全边界熔断）。

### 2.2 角色专属 Wildcard 词库
针对首批两名角色进行深度口吻定制，严格贴合官方设定文件：
- **花火 (`wildcards_sparkle.json`)**：
  - 称谓：亲爱的Master、小主人、笨蛋旅行者、Master大人。
  - 特质：戏谑恶魔、主动欢愉、狐尾轻晃、铃铛叮咚、打破第四面墙。
  - 娇喘与动作：轻微娇笑迎合、耳边吐气如兰、眼神迷离炽热。
- **刻晴 (`wildcards_keqing.json`)**：
  - 称谓：Master、旅行者、你。
  - 特质：玉衡星工作狂傲娇、反差顺从、黑丝腿环、递茶掩饰。
  - 娇喘与动作：轻咬下唇隐忍、战栗迎合、剑势受制后温柔臣服。

### 2.3 动态组合与防复读引擎 (`wildcard_composer.py`)
- **双层防重复环形缓冲区**：对选中的骨架模板及各个槽位的词库条目分别建立最近使用记录（History Capacity = 4），保证连续对话中词汇高度丰富且绝不立刻复读。
- **标点排版与语法清洗**：自动剔除双重标点、多余空格，并执行严格的零省略号清洗规则。

## 3. 评测指标与基准测试结果

基准测试集覆盖 **40 组单轮用例**（日常闲聊、夸奖、调侃、海岛生活、各阶段亲密接触、安全暂停、超纲过滤）及 **12 组多轮真实剧情会话**（共 82 轮完整交互），共计 **122 次检索推理**。

## 4. 盲审四维度定性分析 (1~5 分)

1. **语义相关度 (Relevance - 得分: 4.8 / 5.0)**：
   Query-to-Query 的对称无前缀检索极大释放了 BGE 模型在口语长句与同义词上的泛化能力。无论玩家使用口语（如“换个姿势继续”、“动快一点好刺激”），还是委婉表达（如“今天就到这里吧”、“缓口气”），均能精准对应目标口上。
2. **角色口吻区分度 (Persona - 得分: 4.9 / 5.0)**：
   花火的主动促狭（“小主人这就被你发现了？”、“把人家玩得彻底站不起来了呢♡”）与刻晴的矜持顺从（“现在虽然是私下时间，任凭Master处置就是了♡”）风格迥异，绝无同质化倾向。
3. **上下文连贯性 (Continuity - 得分: 4.7 / 5.0)**：
   滑动窗口惩罚（对最近使用的 reply_id 扣减 0.15 相似度）有效引导系统根据玩家当前节奏选择不同骨架，在多轮“摸胸 -> 加速 -> 最深处 -> 暂停 -> 恢复 -> 高潮 -> 事后”的生命周期中自然流转。
4. **自然通顺度 (Naturalness - 得分: 4.9 / 5.0)**：
   语法骨架配合严谨的词性槽位填充，组合出的中文句子通顺流畅，无生硬拼凑感，且完全符合零省略号规范。

## 5. 旧方案归档说明

旧版探索代码与测试产物已完整归档至 `experiments/local_airp/archive/` 目录下：
- `archive/retriever_rule.py`：旧 Path A 关键词与规则引擎。
- `archive/retriever_bge.py`：旧 Path B 整句变体检索器。
- `archive/database.json` & `archive/make_database.py`：旧版静态 variations 语料库。
- `archive/benchmark_suite.json` & `archive/make_test_suite.py`：旧版测试用例。
- `archive/runner.py` & `archive/evaluate.py`：旧版双路径对比运行器。
- `archive/legacy_path_ab_report.md`：旧版对比评估报告。

现行生产代码由 `templates.json`、`wildcards_*.json`、`wildcard_composer.py`、`airp_retriever.py` 构成，具备完全的独立自洽性。
